# 从这里开始

按照这个顺序操作，完成三个 AI 机器人的创建，然后就能使用它们了。

---

## 第一步：创建三个机器人

1. 打开 **[飞书开发者后台](https://open.feishu.cn/app)**，点「创建应用」
2. 分别创建三个应用：

| 名称 | 角色 | 能力 |
|:---|:---|:---|
| **产品总监** | 团队管理者 | 分配任务、做总结、发号施令 |
| **产品经理** | 产品分析 | 分析用户需求、市场机会 |
| **研发工程师** | 技术评估 | 评估可行性、成本、周期 |

3. 每个应用创建后，去左侧 **「应用功能」→「机器人」**，打开机器人开关
4. 去左侧 **「凭证与基础信息」**，复制 **App ID** 和 **App Secret** 保存好

> 权限默认都有，不需要额外配置。

---

## 第二步：把机器人加到群聊

1. 打开飞书客户端，进入你要使用的群聊
2. 群设置 → **「群机器人」** → **「添加机器人」**
3. 搜索你刚创建的应用名称，三个都加进去

记下 **群聊 ID**：群设置 → 群二维码/链接 → 链接末尾 `oc_` 开头的部分

---

## 第三步：运行

打开终端，进入项目目录：

```powershell
cd cli
.\lark-cli.ps1 ai chat --chat-id oc_这里填你的群聊ID --text "分析AI客服方案"
```

你会看到群里三个机器人依次发言：

```
产品总监 → 指派任务
产品经理 → 做产品分析
产品总监 → 指派技术评估
研发工程师 → 做技术评估
产品总监 → 输出完整结论
```

---

## 做完之后

| 你需要在手边 | 用途 |
|:---|:---|
| 三个 App ID 和 App Secret | 配置 Zeabur 部署时需要 |
| 群聊 ID | 运行 CLI 和部署时都需要 |
| DeepSeek API Key | AI 讨论需要，脚本内置了，也可以换自己的 |
