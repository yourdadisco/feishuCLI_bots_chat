# 飞书机器人创建教程

本文档教你从零创建本项目所需的三个飞书应用，并完成配置。

---

## 你需要创建三个应用

| 应用 | 角色 | 用途 |
|:---|:---|:---|
| **产品总监** | 团队调度者 | 接收用户 @消息、指派任务、出总结 |
| **产品经理** | 产品分析 | 分析用户需求、市场机会 |
| **研发工程师** | 技术评估 | 评估技术可行性、成本、周期 |

---

## 第一步：创建应用

1. 打开 **[飞书开发者后台](https://open.feishu.cn/app)**
2. 点击 **「创建应用」**
3. 填写应用名称（如 `产品总监`），描述随便填
4. 点击 **「确定」**

重复三次，分别创建：`产品总监`、`产品经理`、`研发工程师`

> 应用名称可以随便起，但建议和角色名一致，方便识别。

---

## 第二步：开启机器人能力

1. 进入应用 → 左侧 **「应用功能」** → **「机器人」**
2. 打开 **「启用机器人」** 开关

> 三个应用都要开。

---

## 第三步：添加权限

1. 进入应用 → 左侧 **「权限管理」**
2. 点击 **「添加权限」**，搜索并添加以下权限：

| 权限 | 用途 |
|:---|:---|
| `im:message.group_at_msg.include_bot:readonly` | **必须** 接收群聊中 @机器人的消息 |
| `im:message` | 发送消息 |
| `im:chat` | 群聊管理 |

> **三个应用都要加同样的权限。**

---

## 第四步：获取凭证

1. 进入应用 → 左侧 **「凭证与基础信息」**
2. 找到 **App ID** 和 **App Secret**
3. 复制并保存好，后面配置要用

---

## 第五步：配置事件订阅（仅云部署需要）

如果你要用 **Zeabur 云端方案**（方案二），需要配置事件订阅：

1. 进入应用 → 左侧 **「事件与回调」**
2. 在 **「请求地址配置」** 填入你的 Zeabur 域名：
   ```
   https://你的域名.zeabur.app
   ```
3. 点击 **「添加事件」** → 搜索 `im.message.receive_v1` → 勾选 → 确认
4. 点击 **「完成」**（飞书会发验证请求，服务端自动响应）
5. 保存配置

> **三个应用都要配置事件订阅。**
>
> 如果只用方案一（本地 CLI），不需要配置事件订阅。

---

## 第六步：发布上线

1. 进入应用 → 左侧 **「版本管理与发布」**
2. 点击 **「创建版本」**
3. 填写版本号（如 `1.0.0`）、更新说明
4. 点击 **「保存」** → **「申请发布」**
5. 如果企业开启了审核，联系管理员通过

> 每次修改权限后都需要重新发布才能生效。

---

## 第七步：把机器人拉进群

1. 打开飞书客户端
2. 进入要使用的群聊
3. 点击群设置 → **「群机器人」**
4. 点击 **「添加机器人」**
5. 搜索你创建的应用名称（如 `产品总监`），添加
6. 重复操作，把三个机器人都加进群

---

## 完整配置清单

配置完成后，你手上应该有这些东西：

```
产品总监:
  App ID: cli_xxxxxxxxxxxxxxxxxx
  App Secret: xxxxxxxxxxxxxxxxxxxx

产品经理:
  App ID: cli_xxxxxxxxxxxxxxxxxx  
  App Secret: xxxxxxxxxxxxxxxxxxxx

研发工程师:
  App ID: cli_xxxxxxxxxxxxxxxxxx
  App Secret: xxxxxxxxxxxxxxxxxxxx

群聊 ID: oc_xxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

> 群聊 ID 获取方式：打开群聊 → 群设置 → 群二维码/链接 → 链接末尾 `oc_` 开头的部分

---

## 常见问题

**Q: 机器人发不了消息？**
检查权限是否添加完整，并重新发布版本。

**Q: 群聊里 @产品总监 没人回复？**
- 方案一：运行 `.\cli\lark-cli.ps1 ai chat ...` 手动触发
- 方案二：检查 Zeabur 是否正常运行，事件订阅 URL 是否配置正确

**Q: 需要多大权限才能跑？**
只用了 `im:message` 相关权限，不需要通讯录、文档等权限。
